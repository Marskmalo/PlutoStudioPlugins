Pluto GameplayTag Inspector icon slots

Place PNG files in this folder using the following names:

- Icon128.png : Plugin Browser icon
- Icon20.png  : Main menu / submenu icon
- Icon16.png  : Dock tab icon

Recommended:

- Use square PNG files with transparent backgrounds.
- Keep the visual motif consistent across all three sizes.
- After replacing any icon file, restart Unreal Editor to reload the style set.
